STOP : Arrête immédiatement n'importe quel programme en cours (si le robot se trompe ou si vous voulez reprendre la main).

Bon/OK : Remplit la pièce actuelle (État Bon, Propreté OK, Fonctionne).

TT (Tout Traiter) : Lance le remplissage automatique sur toutes les pièces de la mission.

Réduire : Cache la barre pour libérer l'espace visuel.

Principe de fonctionnement

1 Téléchargez votre mission sur Check & Visit.

2 Allez sur la page Pièce (icône maison 🏠). La mission doit être vierge.

3 Appuyez sur OK (pour la pièce) ou TT (pour tout l'appartement).

Alertes sonores :
  • 1 Bip : Fin du traitement d'une pièce.
  • 3 Bips : Tout est terminé !
Supprimer la barre : Pour fermer l'application, restez appuyé sur la barre et glissez-la vers le bas de l'écran sur la bande rouge qui apparaît.

À savoir avant d'utiliser

  • Sensibilité : L'application simule des clics. Les notifications peuvent perturber le robot. Mettez-vous hors-ligne ou en mode "Ne pas déranger".
  • Écrasement : Si une pièce est déjà remplie, utiliser OK ou TT supprimera vos anciennes infos pour mettre "Bon/OK".
  • Murs & Revêtements : Seul le Mur A est rempli. Les autres murs et les revêtements restent vides.
  • Localisation : Le bandeau ne fonctionne que dans la page "Pièce" de Check & Visit.

Installation simple

1. Téléchargez l'APK via le bouton en haut de page.

2. Autorisez l'installation de sources inconnues dans vos paramètres Android.

3. Activez l'autorisation "S'afficher par-dessus les autres applications".

4. Activez le "Service d'accessibilité" pour permettre au robot de cliquer.
