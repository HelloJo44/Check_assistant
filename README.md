# Check Assistant - Assistant Flottant

Check Assistant est une application Android conçue pour faciliter l'automatisation de tâches (comme le nettoyage) via un bouton flottant et un service d'accessibilité.

## 🚀 Fonctionnement Global
L'application utilise un **Service d'Accessibilité** pour interagir avec l'interface utilisateur et un **Bouton Flottant** (overlay) qui reste visible au-dessus des autres applications. Cela permet de déclencher des actions spécifiques sans avoir à quitter l'application en cours d'utilisation.

## 📥 Procédure d'Installation
1. Téléchargez le dernier fichier `.apk` depuis l'onglet [Releases](https://github.com/HelloJo44/Check_assistant/releases).
2. Transférez le fichier sur votre téléphone Android.
3. Ouvrez le fichier `.apk`. Si votre téléphone vous le demande, autorisez l'installation depuis des sources inconnues.
4. Lancez l'application **Check Assistant**.

## 🛠️ Configuration Requise
Pour que l'application fonctionne correctement, vous devez accorder les permissions suivantes lors du premier lancement :
1. **Superposition d'écran (Overlay)** : Pour afficher le bouton flottant.
2. **Service d'Accessibilité** : Allez dans *Paramètres > Accessibilité > Services installés* et activez **Check Assistant**.
3. **Optimisation de la batterie** : Désactivez l'optimisation pour cette application afin d'éviter qu'Android ne ferme le service en arrière-plan.

## ⚠️ Recommandations d'Usage
- Assurez-vous que le service d'accessibilité est bien activé si le bouton ne répond plus.
- En cas de ralentissement du système, redémarrez l'application.
